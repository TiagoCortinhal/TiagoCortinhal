# Hi, I'm Tiago Cortinhal

Researcher working on Computer Vision.

## Research

I did my PhD at Halmstad University on fusing diverse sensory data — dealing with partial observations, domain gaps, and complex 3D scenes. Some things I'm proud of:

- **[Best PhD Student Paper Award](https://hh.diva-portal.org/smash/get/diva2:1849702/FULLTEXT02.pdf)** for "Semantics-aware Multi-modal Domain Translation" ([university news release](https://www.hh.se/english/about-the-university/schools/school-of-information-technology/news-from-ite/2021-09-02-award-for-best-paper-to-phd-student.html))
- Published work on semantic segmentation and 3D data synthesis — [Google Scholar](https://scholar.google.com/citations?user=mQFOkfcAAAAJ&hl=en)

## Projects

**[SalsaNext](https://github.com/TiagoCortinhal/SalsaNext)** — Fast, uncertainty-aware semantic segmentation for LiDAR point clouds. 400+ citations and still used as a benchmark.

**[TITAN-Next](https://github.com/TiagoCortinhal/TITAN-Next)** — RGB-to-depth generation, bridging 2D images and 3D geometry.

**[Pseudo Point Cloud Generation](https://ieeexplore.ieee.org/document/10588782)** — Data-driven 3D point cloud synthesis from 2D inputs.
